# 🎣 Chiripi Pesca

Proyecto web de e-commerce desarrollado como práctica de frontend.
Simula una tienda de artículos de pesca con funcionalidades básicas de interfaz y estructura dinámica.

---

## 🚀 Funcionalidades

* Header con:

  * Logo personalizado
  * Barra de búsqueda
  * Botón de inicio de sesión
  * Carrito de compras
* Render dinámico de productos con JavaScript
* Diseño responsive básico con Flexbox
* Integración de íconos con Font Awesome

---

## 🧱 Tecnologías utilizadas

* HTML5
* CSS3 (Flexbox)
* JavaScript (DOM Manipulation)
* Font Awesome (íconos)

---

## 📦 Estructura del proyecto

## 🧠 Conceptos aplicados

* Manipulación del DOM con `innerHTML`
* Uso de `flexbox` para layout moderno
* Separación de responsabilidades (estructura / estilo / lógica)
* Uso de eventos en JavaScript
* Componentización básica de UI (header, productos, etc.)
